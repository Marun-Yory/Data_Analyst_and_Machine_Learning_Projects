## Diabetes & Lifestyle Data Analysis and Prediction
### Project Overview

Python (3.14.6 or later)

This project explores the relationship between lifestyle behaviors, demographic characteristics, and health indicators associated with diabetes.

Using Python, Exploratory Data Analysis (EDA), data visualization, and machine learning, the project aims to identify important diabetes risk factors and develop classification models to predict diabetes diagnosis.

### Project Objectives
Analyze demographic and lifestyle factors related to diabetes.
Explore relationships between health indicators and diabetes.
Identify key factors associated with diabetes diagnosis.
Visualize patterns and trends through exploratory data analysis.
Build and evaluate machine learning classification models.
Generate meaningful, data-driven insights.
### Dataset Description

The dataset contains 31 columns covering demographic, socioeconomic, lifestyle, and clinical information.

Category	Features
Demographics	Age, gender, ethnicity
Socioeconomic	Education level, income level, employment status
Lifestyle	Smoking status, alcohol consumption, physical activity, diet score
Health Indicators	HDL, LDL, triglycerides, glucose, insulin, HbA1c
Diabetes Information	Diabetes risk score, diabetes stage, diagnosed diabetes

#### Target Variable: diagnosed_diabetes

0 = No Diabetes
1 = Diabetes
#### Tools & Technologies
Python: Data analysis and programming
Pandas & NumPy: Data cleaning and manipulation
Matplotlib & Seaborn: Data visualization
Scikit-learn: Machine learning and model evaluation
Jupyter Notebook: Data analysis environment
### Project Workflow
Data Understanding: Explore dataset structure, features, and distributions.
Data Cleaning: Handle missing values, duplicates, and outliers.
Exploratory Data Analysis: Investigate demographic, lifestyle, and clinical patterns.
Data Visualization: Create charts and correlation heatmaps.
Feature Engineering: Prepare features for machine learning.
Model Building: Train classification models such as Logistic Regression, Decision Tree, Random Forest, and XGBoost.
Model Evaluation: Compare models using Accuracy, Precision, Recall, F1-score, and ROC-AUC.
### Expected Outcomes
Identify important factors associated with diabetes.
Understand relationships between lifestyle and health indicators.
Discover meaningful patterns through data visualization.
Develop machine learning models for diabetes classification.
Provide data-driven insights to support diabetes risk awareness.
