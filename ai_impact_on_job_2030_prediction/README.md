## AI Impact on Jobs 2030: Data Analysis & Prediction
### Project Overview

Python (3.14.6 or later)

This project explores how Artificial Intelligence (AI) may impact different occupations by 2030. It analyzes job roles, salary levels, work experience, education, AI exposure, technology growth, and automation probability to understand potential changes in the future workforce.

Using Python, Exploratory Data Analysis (EDA), data visualization, and machine learning, the project aims to identify jobs at higher risk of automation and uncover patterns that may influence future employment opportunities.

### Project Objectives
Analyze AI exposure across different job roles.
Identify occupations with high automation probability by 2030.
Explore relationships between salary, education, and work experience.
Investigate the relationship between AI exposure and automation risk.
Identify skills associated with different occupations.
Build machine learning models to classify job automation risk.
Generate insights into future workforce trends.
### Dataset Description

The dataset contains 18 features covering employment, education, AI impact, and occupational skills.

Feature	Description
Job_Title	Occupation name
Average_Salary	Average annual salary
Years_Experience	Required or recorded work experience
Education_Level	Educational qualification
AI_Exposure_Index	Level of exposure to AI
Tech_Growth_Factor	Technology growth indicator
Automation_Probability_2030	Estimated automation probability
Risk_Category	Job automation risk (Low, Medium, High)
Skill_1 – Skill_10	Occupational skill indicators

### Project Workflow
Data Understanding: Explore dataset structure and statistical summaries.
Data Cleaning: Handle missing values, duplicates, and inconsistent data.
Exploratory Data Analysis: Analyze job trends, salaries, AI exposure, and automation risk.
Data Visualization: Create charts, distributions, and correlation heatmaps.
Feature Engineering: Encode categorical variables and prepare model features.
Machine Learning: Apply classification algorithms such as Logistic Regression, Decision Tree, Random Forest, and XGBoost.
Model Evaluation: Evaluate performance using Accuracy, Precision, Recall, F1-score, and Confusion Matrix.
### Expected Outcomes
Identify occupations with high AI exposure.
Understand potential automation risks across industries.
Discover relationships between education, experience, salary, and automation.
Identify important factors influencing job risk categories.
Develop machine learning models to classify automation risk.
Generate insights to support future career and workforce planning.
