## Financial Risk Analysis & Loan Approval Prediction
### Project Overview

Python (3.14.6 or later)

This project analyzes financial and customer data to understand the factors influencing loan approval decisions and financial risk.

Using Python, Exploratory Data Analysis (EDA), data visualization, and machine learning, the project aims to identify key loan approval indicators, assess customer financial profiles, and develop predictive models to classify loan applications.

### Project Objectives
Analyze customer demographics and financial characteristics.
Identify factors influencing loan approval decisions.
Explore relationships between income, credit scores, debt, and loan approval.
Investigate customer financial risk patterns.
Build machine learning models to predict loan approval.
Generate insights to support data-driven lending decisions.
### Dataset Description

The dataset contains 36 features covering customer demographics, employment, financial history, loan details, and approval outcomes.

Category	Features
Customer Information	Age, MaritalStatus, EducationLevel
Employment	EmploymentStatus, Experience, JobTenure
Financial Profile	AnnualIncome, MonthlyIncome, NetWorth, CreditScore
Loan Information	LoanAmount, LoanDuration, InterestRate, MonthlyLoanPayment
Financial Risk	TotalDebtToIncomeRatio, RiskScore, UtilityBillsPaymentHistory
Target Variable	LoanApproved

#### Target Variable: LoanApproved

0 = Loan Not Approved
1 = Loan Approved
### Tools & Technologies

### Project Workflow
Data Understanding: Explore dataset structure and statistical summaries.
Data Cleaning: Handle missing values, duplicates, and outliers.
Exploratory Data Analysis: Investigate customer financial profiles and approval patterns.
Data Visualization: Create distributions, comparison charts, and correlation heatmaps.
Feature Engineering: Encode categorical variables and prepare model features.
Machine Learning: Apply Logistic Regression, Decision Tree, Random Forest, and XGBoost.
Model Evaluation: Compare models using Accuracy, Precision, Recall, F1-score, and ROC-AUC.
### Expected Outcomes
Identify important factors affecting loan approval.
Understand customer financial risk profiles.
Discover patterns in credit scores, income, and debt levels.
Develop machine learning models for loan approval prediction.
Generate actionable insights for financial risk assessment.
