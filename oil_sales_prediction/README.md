## Oil Sales Data Analysis & Prediction
### Project Overview

Python (3.14.6 or later)

This project analyzes cooking oil sales data to understand sales performance, customer purchasing patterns, product popularity, and pricing trends across different cities and stores.

Using Python, Exploratory Data Analysis (EDA), data visualization, and machine learning, the project aims to identify key sales drivers, forecast sales performance, and generate actionable business insights.

### Project Objectives
Analyze sales performance across cities, stores, brands, and manufacturers.
Identify best-selling oil products and product categories.
Explore relationships between price, sales volume, and revenue.
Analyze monthly and yearly sales trends.
Identify key factors influencing sales performance.
Build machine learning models to predict sales and demand.
### Dataset Description

The dataset contains 13 features related to product information, store locations, pricing, and sales performance.

Feature	Description
city	Sales location
store_name	Store identification
manufacturer	Product manufacturer
brand	Product brand
class	Oil product category
size	Product packaging size
sku	Stock Keeping Unit
price_bracket	Product price range
year	Sales year
month	Sales month
value_sales	Total sales revenue
volume_sales	Total sales volume
average_price	Average selling price
### Tools & Technologies
Python: Data analysis and programming
Pandas & NumPy: Data cleaning and manipulation
Matplotlib & Seaborn: Data visualization
Scikit-learn: Machine learning and model evaluation
Jupyter Notebook: Interactive data analysis
### Project Workflow
Data Understanding: Explore dataset structure and statistical summaries.
Data Cleaning: Handle missing values, duplicates, and inconsistent data.
Exploratory Data Analysis: Analyze sales, pricing, brands, and product performance.
Data Visualization: Create sales trends, comparison charts, and correlation heatmaps.
Feature Engineering: Prepare relevant features for machine learning.
Machine Learning: Apply regression models such as Linear Regression, Random Forest, and XGBoost.
Model Evaluation: Evaluate predictions using MAE, RMSE, and R².
### Expected Outcomes
Identify top-performing brands, products, and cities.
Understand monthly and yearly sales trends.
Discover relationships between price and sales volume.
Identify key factors influencing sales revenue.
Predict future sales and product demand.
Generate actionable insights for business decision-making.
